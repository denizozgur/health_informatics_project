# Participant table and data availability

This step builds **one row per LEMON participant**. The row combines:

- demographics (META file);
- anthropometry and blood pressure;
- the STAI, PSQ and TICS questionnaires;
- availability flags: whether the LEMON tables list ECG, resting-state fMRI, EEG and physiology for that person.

The table is the shared starting point for the other tasks. It decides who can be included in which analysis.

**See the results:** [overview.ipynb](overview.ipynb) shows the table's contents, who the participants are, what data they have, the main measures by age group, and missing values. It shows group-level numbers only.

## Run (in this order)

```bash
uv run python analysis/participant_table/scripts/build_master_table.py
```

```bash
uv run python analysis/participant_table/scripts/availability_flags.py
```

```bash
uv run python analysis/participant_table/scripts/data_dictionary.py
```

The scripts read `data/LEMON/` and never change it. Each takes about a second.

## Main results

- **Participants:** 228 IDs, which are the 227 in META plus one that appears only in the follow-up table.
  - 82 female and 145 male.
  - 153 younger (20-40) and 74 older (55-80); nobody is aged 40-55.
- **Stress questionnaires:** 220 people have both PSQ and TICS. PSQ is higher in the younger group (33.2 vs 23.8).
- **Listed as available:**
  - ECG: 213;
  - rs-fMRI: 226;
  - both: 212;
  - both plus PSQ: 206.
  - Follow-up physiology runs: ECG 98, blood pressure 102, PPG 102, respiration 98.

## Caveats and open questions

- **Availability ≠ usable data.** A flag only says a measurement is *listed* as available. Whether the files exist and are usable is checked per modality; see `fmri_eda` for the fMRI.
- **Undefined Day-1 columns.** The Day-1 `ECG` column, and the beat-to-beat blood pressure, photoplethysmography and respiration columns, are not defined in the LEMON info file. What they record, and whether it was during the MRI, is **unclear**.
- **Follow-up physiology timing.** The follow-up physiology runs are named after rs-fMRI runs 1-4. Whether they were recorded at the same time as the scan is **unclear**.
- **Missing variables.** There are no medication, caffeine, physical-activity or time-of-day variables.
- **Small cells.** Some age × sex cells have only 1-2 people; treat them with care before reporting.

## Reproducibility

The scripts replace the original ones, kept unchanged in a local `archive/` folder (not on GitHub). Every original output was regenerated byte-identically: the master table, the table with flags, the slim table, the build log, the five original results tables and the data dictionary.
